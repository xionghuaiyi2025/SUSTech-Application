## 项目说明
使用Python对常德市疫情数据进行线性回归预测，包含：
- 数据清洗
- 模型构建
- 可视化分析

## 运行环境
- Python 3.8+
- 所需库：`pip install pandas matplotlib scikit-learn`

## 使用方式
1. 下载本仓库
2. 运行命令：`python covid_prediction.py`
3. 查看生成的结果图`result.png`
